# Handoff — M4 billing implemented locally

## Starting point and user direction

Cloned `vaibhavforeal/Restaurant-Billing-System` into the previously empty
workspace from `main` at `3fa2786`. User asked to pick up unfinished work.
The August 15 handoff identified M4 Billing as next. User specifically requested
**both GST-inclusive and GST-exclusive menu prices, configurable**.

## Delivered

- Integer-paise GST engine, proportional discounts across rate groups,
  nearest-rupee final rounding. Inclusive extraction conserves the discounted
  gross amount, assigning an odd tax paise to CGST. Existing cashier 10% limit
  enforced server-side, and discounts require reasons.
- Migration 005 adds `settings.tax_inclusive` (default false), saved receipt and
  request JSON, unique billing references, and a settlement/audit table. Prior
  migrations are unchanged. A settings PUT that omits the tax mode preserves it.
- Preview fingerprint detects concurrent order/profile changes. Issuing assigns
  bill number, saves taxes/snapshots and changes order state in one transaction.
  Unsent kitchen items block billing; remaining stationless items become sent.
- Exact cash/UPI/card split settlement, atomic with order close and actor record.
  Zero bills settle with no payment rows. Replays return original results;
  conflicting request-reference reuse is rejected. Tables free after all splits
  settle. Billed parcels remain accessible in Tables and Bills.
- 58/80mm ESC/POS receipt templates and authenticated HTML receipt with browser
  print/save-PDF UI. Receipt profiles, item names/prices/rates, table labels and
  tax mode are frozen. Receipt printer choice is remembered per browser.
- Bills page with unpaid/paid/all filters and paged history; order billing panel;
  day-end report with per-rate tax, issued sales, current unpaid amount, payment
  collections by payment date, and order cancellations by close date.
- Queue no longer drops live/failed jobs above 100 entries: trims only completed
  history. Exported the existing print `contextLine` helper for receipt reuse.
