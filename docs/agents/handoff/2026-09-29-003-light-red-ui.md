# Light and red UI — 0.6.1

User requested a light interface with red as the accent. Implemented in the
existing React/Vite/Electron application, with no new dependencies or external
fonts. Earlier M4/M5/M6 changes remain uncommitted; preserve them.

## Changes

- Shared light theme, red primary actions, SVG icons and responsive navigation.
- Dashboard counts come from saved orders and tables, refreshed over WebSocket.
- Table cards, status filters, table/area search and clear empty states.
- Searchable dish cards with portions, an independently scrolling desktop cart,
  phone cart shortcut, accessible quantity/variant controls and readable totals.
- Matching checkout, kitchen tickets, PIN login, setup and admin screens.
- Settings waits for saved values before showing its editable form, preventing
  early edits from being overwritten. Backup controls have their own section.
- Page changes return to the top. The desktop icon now uses the red accent.
- Version bumped to 0.6.1; previous 0.6.0 installer retained.
