# Simplified interface — 0.6.2

User liked the light/red theme but requested fewer details and a dashboard
without scrolling. Simplified the existing UI without changing billing logic.

- Dashboard: three live totals, New order, and four role-aware service shortcuts.
  Removed greeting, welcome banner, descriptions and duplicate admin shortcuts.
- Removed the redundant breadcrumb bar, brand subtitle and sidebar section label.
  Compact sidebar spacing adapts to shorter desktop windows.
- Removed promotional page subtitles and repeated decorative menu icons.
  Reduced table/menu card height and shortened routine helper text.
- Login/setup now use a simple centered card with no marketing copy.
- Kept tax explanations, payment controls, stock warnings, error messages and
  consequential setup/recovery instructions.
