# Keyboard shortcuts

An administrator can configure **Settings > Keyboard shortcuts** on each counter.
Bindings apply to everyone using that browser profile and URL, persist across
restarts, and update other open tabs for the same origin. Other counters keep
their own configuration. These settings do not change staff permissions.

| Action | Default |
| --- | --- |
| New order (last-used entry screen) | F2 |
| Tables | F3 |
| Discount / bill options | F4 |
| Save items (punch without kitchen send) | F6 |
| Takeaway | F7 |
| Hold order | F8 |
| Send to kitchen | F9 |
| Billing / payment | F10 |

Choose a key or **Disabled** for each action, then **Save shortcuts**. Duplicate
assignments are marked and block saving. You can swap two assignments before
saving. **Reset to defaults** selects the defaults; save to apply them.
**Discard changes** reloads the saved settings. A storage failure is reported and
does not display a success message. If another tab saves while you are editing,
discard your draft before saving a replacement.

Supported keys are F2, F3, F4, F6, F7, F8, F9 and F10, plus Shift with those keys
except F10. Help, refresh, fullscreen, developer-tool and context-menu keys are
excluded. Normal typing is unaffected. Button text, tooltips, accessible shortcut
attributes and the status-bar hints follow the saved configuration.

A shortcut invokes its visible, enabled button. Takeaway is available from Home,
Tables, and Next takeaway after an order is paid. Save items and kitchen-send
remain available only where those controls are shown. Hidden, disabled, or
unauthorized actions cannot be triggered. With a dialog open, shortcuts stay
inside that dialog; changing shortcuts in their settings section does not run
POS actions. Holding a key down does not repeat a transaction.

The billing key follows the existing review and confirmation sequence. It does
not skip a bill preview or confirm a payment that has not been reviewed. Read the
visible button and confirm actual payment before using it for the final step.

Other operation guides show the default keys. Use the keys displayed by your
application if this counter has custom bindings.
