# Order types

Order types say how an order is served: Dine-in, Takeaway, Zomato, and any takeaway or
delivery types you add, such as **Home delivery** or **Counter pickup**. Available on Basic and Pro.

## Set up order types (admin)

1. Open **Settings → Order types**.
2. Enter a name, choose **Delivery** or **Takeaway**, and choose **Add order type**.
3. Use **Rename** to change a name, and **Turn off** to stop offering a type. A type that has been
   used is never deleted, so past reports keep it.

The built-in types (Dine-in, Takeaway, Zomato) can be renamed but not turned off.

## Use an order type

Your own types work like takeaway orders: no table, and items use their takeaway price.

1. Start a takeaway (Quick takeaway or **New parcel**).
2. In the order header, choose the **Order type**. The choice appears once you have added at least
   one type of your own, and can be changed while the order is open.

The type name prints on kitchen tickets and slips (instead of "Parcel"), shows on the kitchen
screen, and is saved on the bill and receipt. Renaming a type later does not change bills already issued.

## Reports

**Reports → Order type sales** lists, for each order type, the bills issued, subtotal, discount,
GST, credit notes, net sales and average bill. Bills count on their bill date; voids and refunds
subtract on their own date from the order type of the bill they credit.
