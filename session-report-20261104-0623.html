recommendations

Split broad requests like the licensing web portal prompt (10.9% of total) into separate specs and sessions. Each part then starts from a small context instead of running for hundreds of API calls in one conversation.
Agent-team and subagent-driven runs cost the most. "can you start executing with agent teams" was 5.4% (32 subagents), and superpowers:subagent-driven-development was 6.3%. Inline (native) execution with one final reviewer did the hold-order feature for 3.1%. Prefer it when the tasks build on each other.
Avoid switching /model mid-session in long Restaurant Billing Software sessions. The 30 Oct switch caused the largest cache break (877k tokens re-read). Start a new session for the new model instead.
Give general-purpose subagents narrow, read-only briefs, or use Explore for searches. Explore averaged far fewer tokens per session (14M over 7 sessions, against 131M over 6).
